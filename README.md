# 🔧 PlombierTool

**PlombierTool** est une application conçue pour les plombiers, chauffagistes et apprentis afin de regrouper des outils pratiques du métier au même endroit.

L'objectif : avoir une **boîte à outils numérique** simple, rapide et accessible sur téléphone ou ordinateur. 📱💻

## 🚀 Fonctionnalités

* 🧰 Outils pratiques pour la plomberie
* 📐 Calculs et conversions utiles
* 🔩 Informations sur différents matériaux et raccords
* 📏 Aide aux mesures et dimensions
* 💾 Sauvegarde locale des données
* 📱 Interface adaptée aux appareils mobiles
* ⚡ Utilisation rapide et simple
* 🌐 Version Web
* 📦 **Version Android APK disponible**

## 📱 Télécharger PlombierTool

### Android

Une version **APK** de PlombierTool est disponible pour Android.

👉 **[Télécharger l'APK](../../releases/latest)**

## 💾 Données

PlombierTool utilise le **stockage local** pour certaines données.

Les informations sauvegardées peuvent donc rester directement sur l'appareil et ne nécessitent pas forcément de compte.

⚠️ La suppression des données de l'application ou du navigateur peut entraîner la perte des données locales.
